Mit értünk Node.js esetén esemény (event) alatt?

A Node.js-ben az esemény (Event) egy olyan jelzés, amely arról tájékoztatja a programot, hogy valamilyen művelet vagy történés bekövetkezett. Amikor egy esemény bekövetkezik, a hozzá tartozó eseménykezelő (Event Listener) automatikusan lefut.

A Node.js működésének egyik alapja az eseményvezérelt (event-driven) programozás, amely lehetővé teszi, hogy a program hatékonyan kezeljen sok egyidejű műveletet (például hálózati kéréseket vagy fájlműveleteket) anélkül, hogy folyamatosan várakozna.

Mi az esemény?

Egy esemény lehet például:

  • egy fájl sikeres beolvasása;
  • egy HTTP kérés érkezése;
  • egy TCP kapcsolat létrejötte;
  • egy időzítő lejárata;
  • egy felhasználói művelet (böngészőben);
  • egy hiba bekövetkezése.

Eseményvezérelt működés

A Node.js nem folyamatosan ellenőrzi, hogy történt-e valami, hanem várakozik az eseményekre.

Amikor egy esemény bekövetkezik:

Esemény bekövetkezik
        │
        ▼
Node.js érzékeli
        │
        ▼
Meghívja az eseménykezelőt
        │
        ▼
A program végrehajtja a megfelelő kódot

Az EventEmitter

A legtöbb Node.js esemény a node:events modul EventEmitter osztályára épül.

Importálás:

ECMAScript Modules (ESM)

import { EventEmitter } from 'node:events';

CommonJS

const { EventEmitter } = require('node:events');

1. Saját esemény létrehozása

import { EventEmitter } from 'node:events';

const emitter = new EventEmitter();

emitter.on('koszones', () => {
    console.log('Szia!');
});

emitter.emit('koszones');

Kimenet:

Szia!

Mi történt?

emit("koszones")
        │
        ▼
on("koszones")
        │
        ▼
console.log("Szia!")

Az emit() kiváltotta a koszones eseményt.

2. Esemény adatokkal

Az esemény paramétereket is átadhat.

import { EventEmitter } from 'node:events';

const emitter = new EventEmitter();

emitter.on('felhasznalo', (nev) => {
    console.log(`Üdv ${nev}!`);
});

emitter.emit('felhasznalo', 'Anna');

Kimenet:

Üdv Anna!

3. Több paraméter

emitter.on('osszeg', (a, b) => {
    console.log(a + b);
});

emitter.emit('osszeg', 12, 8);

Kimenet:

20

4. Több eseménykezelő ugyanarra az eseményre

const emitter = new EventEmitter();

emitter.on('start', () => {
    console.log('Első.');
});

emitter.on('start', () => {
    console.log('Második.');
});

emitter.emit('start');

Kimenet:

Első.
Második.

Mindkét eseménykezelő lefut.

5. Egyszer futó esemény (once())

const emitter = new EventEmitter();

emitter.once('hello', () => {
    console.log('Csak egyszer.');
});

emitter.emit('hello');
emitter.emit('hello');

Kimenet:

Csak egyszer.

A once() csak az első eseménynél fut le.

6. Eseménykezelő eltávolítása

function koszon() {
    console.log('Szia!');
}

emitter.on('hello', koszon);

emitter.off('hello', koszon);

emitter.emit('hello');

Nem történik semmi, mert a kezelőt eltávolítottuk.

7. HTTP szerver eseménye

A node:http modul is eseményeket használ.

import http from 'node:http';

const server = http.createServer();

server.on('request', (req, res) => {
    res.end('Hello!');
});

server.listen(3000);

Amikor egy böngésző kapcsolódik:

HTTP kérés
      │
      ▼
request esemény
      │
      ▼
A callback lefut

8. Fájl olvasása streammel

import fs from 'node:fs';

const stream = fs.createReadStream('hello.txt');

stream.on('data', (chunk) => {
    console.log(chunk.toString());
});

A data esemény minden új adatblokk érkezésekor lefut.

9. A fájl végének jelzése

stream.on('end', () => {
    console.log('Kész.');
});

10. Hibakezelés

stream.on('error', (err) => {
    console.log(err.message);
});

Ha a fájl nem létezik, az error esemény aktiválódik.

on() és emit()

A két legfontosabb metódus:

on()

Eseményfigyelő regisztrálása.

emitter.on('login', callback);

emit()

Esemény kiváltása.

emitter.emit('login');

Az események működése

Program indul
      │
      ▼
Eseményfigyelő regisztrálása
      │
      ▼
Valami történik
      │
      ▼
emit(...)
      │
      ▼
Az eseménykezelő lefut

Események a Node.js-ben

A Node.js számos beépített modulja eseményekre épül:

Modul Példa események
node:http request, close, connection
node:fs (streamek) data, end, error
node:net connect, close
node:process exit, beforeExit
node:readline line, close

Mikor használjunk saját eseményeket?

Saját eseményeket akkor érdemes létrehozni, ha az alkalmazás különböző részeit lazán szeretnénk összekapcsolni.

Például:

  • egy felhasználó sikeresen bejelentkezett;
  • egy rendelés elkészült;
  • egy fájl feldolgozása befejeződött;
  • új üzenet érkezett egy chat alkalmazásba.

Így az eseményt kiváltó kódnak nem kell tudnia, hogy pontosan mely részek reagálnak rá.

Összefoglalás

A Node.js-ben az esemény egy jelzés arról, hogy valamilyen művelet vagy állapotváltozás bekövetkezett. Az események kezelését az EventEmitter osztály biztosítja, amely lehetővé teszi eseményfigyelők regisztrálását (on(), once()) és események kiváltását (emit()).

Az eseményvezérelt működés a Node.js egyik legfontosabb tulajdonsága: a beépített modulok – például a node:http, a fájlstreamek vagy a node:process – is események segítségével kommunikálnak. Ennek köszönhetően a Node.js hatékonyan tud sok egyidejű műveletet kezelni anélkül, hogy a programnak folyamatosan várakoznia kellene egy-egy feladat befejeződésére.
