Hogyan tudunk fájlokat törölni Node.js segítségével?

A Node.js-ben fájlok törlésére a node:fs (File System) modul vagy annak Promise-alapú változata, a node:fs/promises modul használható.

A fájltörlés történhet:

  • szinkron módon (unlinkSync());
  • aszinkron módon callbackkel (unlink());
  • Promise-alapon (fs/promises.unlink()).

A modern Node.js alkalmazásokban általában a node:fs/promises modul és az async/await használata ajánlott.

1. A node:fs/promises modul importálása

ECMAScript Modules (ESM)

import fs from 'node:fs/promises';

CommonJS

const fs = require('node:fs/promises');

2. Egy fájl törlése (unlink())

Tegyük fel, hogy létezik egy hello.txt fájl.

import fs from 'node:fs/promises';

await fs.unlink('hello.txt');

console.log('A fájl törölve.');

Ha a fájl létezik, a törlés sikeres lesz.

3. Hibakezelés

import fs from 'node:fs/promises';

try {
    await fs.unlink('hello.txt');

    console.log('A fájl törölve.');
} catch (err) {
    console.error(err.message);
}

Ha a fájl nem létezik:

ENOENT: no such file or directory

4. Létezik-e a fájl?

A node:fs/promises modulban használható az access() metódus annak ellenőrzésére, hogy a fájl elérhető-e.

import fs from 'node:fs/promises';

try {
    await fs.access('hello.txt');

    await fs.unlink('hello.txt');

    console.log('Törölve.');
} catch {
    console.log('A fájl nem található.');
}

5. Szinkron fájltörlés (unlinkSync())

import fs from 'node:fs';

fs.unlinkSync('hello.txt');

console.log('A fájl törölve.');

A program megvárja, amíg a törlés befejeződik.

6. Callback-alapú fájltörlés

import fs from 'node:fs';

fs.unlink('hello.txt', (err) => {
    if (err) {
        console.error(err);
        return;
    }

    console.log('Törölve.');
});

Ez a régebbi Node.js programokban gyakori megoldás.

7. Több fájl törlése

import fs from 'node:fs/promises';

const fajlok = ['a.txt', 'b.txt', 'c.txt'];

for (const fajl of fajlok) {
    try {
        await fs.unlink(fajl);

        console.log(`${fajl} törölve.`);
    } catch {
        console.log(`${fajl} nem található.`);
    }
}

8. Mappa törlése

Egy üres mappa törlése:

import fs from 'node:fs/promises';

await fs.rmdir('adatok');

Megjegyzés: Az rmdir() használata új fejlesztéseknél már nem ajánlott. Helyette a rm() metódust érdemes használni.

9. Mappa törlése tartalmával együtt

import fs from 'node:fs/promises';

await fs.rm('adatok', {
    recursive: true,
    force: true,
});

Jelentése:

  • recursive: true → a mappa teljes tartalma is törlődik;
  • force: true → nem dob hibát, ha a mappa nem létezik.

10. Biztonságos törlés

import fs from 'node:fs/promises';

try {
    await fs.rm('hello.txt', {
        force: true,
    });

    console.log('Kész.');
} catch (err) {
    console.error(err);
}

A force: true miatt nem kapunk hibát, ha a fájl nem létezik.

11. Relatív és abszolút útvonal

Relatív útvonal:

await fs.unlink('hello.txt');

Abszolút útvonal:

await fs.unlink('C:\\projekt\\hello.txt');

Platformfüggetlen megoldás:

import fs from 'node:fs/promises';
import path from 'node:path';

const fajl = path.join(process.cwd(), 'hello.txt');

await fs.unlink(fajl);

12. Gyakori hibák

A fájl nem létezik

ENOENT: no such file or directory

Megoldás:

  • ellenőrizd a fájl nevét;
  • ellenőrizd az útvonalat;
  • vagy használd a force: true opciót a rm() metódussal.

Nincs jogosultság

EACCES: permission denied

A programnak nincs jogosultsága a fájl törlésére.

A fájl használatban van

Windows rendszeren előfordulhat:

EBUSY

Ilyenkor a fájlt egy másik alkalmazás használja (például egy szövegszerkesztő vagy víruskereső).

A különböző törlési módok összehasonlítása

Módszer Aszinkron Fájl Mappa Ajánlott
unlinkSync() ✖ ✔ ✖ Egyszerű programokhoz
unlink() ✔ ✔ ✖ Régebbi kódokban
fs/promises.unlink() ✔ ✔ ✖ Igen
fs.rm() ✔ ✔ ✔ Modern megoldás

Mikor melyiket használjuk?

  • fs/promises.unlink() – egy fájl törlésére.
  • fs.rm() – fájlok és mappák törlésére, különösen ha recursive vagy force opcióra is szükség van.
  • unlinkSync() – egyszerű segédprogramokban, amikor nem gond, hogy a program megvárja a törlés befejezését.
  • unlink() – régebbi callback-alapú kódokban.

Összefoglalás

A Node.js-ben a fájlok törlésének klasszikus módja a unlink() metódus, amelynek Promise-alapú változata (node:fs/promises.unlink()) a modern alkalmazásokban a leggyakrabban használt megoldás.

Ha nemcsak fájlokat, hanem teljes könyvtárakat is szeretnél törölni – akár azok tartalmával együtt –, akkor a fs.rm() használata ajánlott. Ez a modern Node.js API egységes megoldást kínál fájlok és mappák eltávolítására, és a recursive valamint force opciókkal rugalmasan kezelhetők a különböző törlési helyzetek.
