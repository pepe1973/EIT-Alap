Hogyan tudunk visszaküldeni html, css állományokat és képeket?

A Node.js node:http modulja önmagában nem tud automatikusan HTML, CSS vagy képfájlokat kiszolgálni. Ezeket nekünk kell beolvasni a fájlrendszerből, majd a megfelelő HTTP fejléccel (Content-Type) elküldeni a kliensnek.

A folyamat minden fájltípusnál ugyanaz:

Böngésző
      │
      │ HTTP kérés
      ▼
Node.js szerver
      │
      ▼
Fájl beolvasása (fs.readFile)
      │
      ▼
Content-Type beállítása
      │
      ▼
res.end(fájl tartalma)
      │
      ▼
Böngésző megjeleníti

1. HTML fájl visszaküldése

Tegyük fel, hogy van egy index.html fájlunk.

projekt/
│
├── server.js
└── index.html

index.html

<!DOCTYPE html>
<html lang="hu">
    <head>
        <meta charset="UTF-8" />
        <title>Node.js</title>
    </head>
    <body>
        <h1>Hello Node.js!</h1>
    </body>
</html>

server.js

import http from 'node:http';
import fs from 'node:fs/promises';

const server = http.createServer(async (req, res) => {
    const html = await fs.readFile('index.html');

    res.writeHead(200, {
        'Content-Type': 'text/html; charset=utf-8',
    });

    res.end(html);
});

server.listen(3000);

A böngésző megnyitja a HTML oldalt.

2. CSS fájl kiszolgálása

Projekt:

projekt/
│
├── server.js
├── index.html
└── style.css

style.css

body {
    background: lightblue;
}

h1 {
    color: darkblue;
}

HTML

<link
    rel="stylesheet"
    href="/style.css"
/>

Server

import http from 'node:http';
import fs from 'node:fs/promises';

const server = http.createServer(async (req, res) => {
    if (req.url === '/') {
        const html = await fs.readFile('index.html');

        res.writeHead(200, {
            'Content-Type': 'text/html; charset=utf-8',
        });

        res.end(html);
    } else if (req.url === '/style.css') {
        const css = await fs.readFile('style.css');

        res.writeHead(200, {
            'Content-Type': 'text/css',
        });

        res.end(css);
    }
});

server.listen(3000);

Amikor a böngésző letölti a HTML-t, automatikusan kérni fogja a CSS fájlt is.

9. Egyszerű statikus fájlkiszolgáló

Az alábbi példa egy kiszolgálót mutat be, amely automatikusan kezeli a HTML, CSS és PNG fájlokat.

import http from 'node:http';
import fs from 'node:fs/promises';
import path from 'node:path';

const server = http.createServer(async (req, res) => {
    let file = '.' + req.url;

    if (file === './') {
        file = './index.html';
    }

    try {
        const data = await fs.readFile(file);

        const ext = path.extname(file);

        let type = 'text/plain';

        switch (ext) {
            case '.html':
                type = 'text/html';
                break;

            case '.css':
                type = 'text/css';
                break;

            case '.png':
                type = 'image/png';
                break;

            case '.jpg':
                type = 'image/jpeg';
                break;
        }

        res.writeHead(200, {
            'Content-Type': type,
        });

        res.end(data);
    } catch {
        res.writeHead(404);

        res.end('404');
    }
});

server.listen(3000);

Ez a megoldás már hasonlít egy egyszerű webszerver működésére.

Összefoglalás

A Node.js node:http moduljával HTML-, CSS- és képfájlokat úgy szolgálhatunk ki, hogy a fájlokat a node:fs/promises modul segítségével beolvassuk, majd a megfelelő Content-Type fejléc beállítása után a res.end() metódussal elküldjük a kliensnek. Minden egyes erőforrás (például egy HTML oldal, egy CSS fájl vagy egy kép) külön HTTP kérésként érkezik a szerverhez, ezért a request handlernek a req.url alapján kell eldöntenie, melyik fájlt küldje vissza. Nagyobb alkalmazásokban ezt a feladatot általában webes keretrendszerek (például Express) vagy statikus fájlkiszolgáló middleware-ek végzik automatikusan.
