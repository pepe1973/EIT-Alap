Mi a feladata a server.listen() metódusnak?

A server.listen() metódus feladata, hogy elindítsa a HTTP szervert, és megadja, hogy melyik hálózati porton várja a beérkező kapcsolatokat.

Fontos megérteni, hogy a http.createServer() csak létrehozza a szerver objektumot, de még nem indítja el. A szerver csak a server.listen() meghívása után kezd el HTTP kéréseket fogadni.

A működés folyamata

http.createServer()
        │
        ▼
Szerver objektum létrejön
        │
        ▼
server.listen()
        │
        ▼
Port megnyitása
        │
        ▼
A szerver várja a kapcsolatokat
        │
        ▼
HTTP kérés érkezik
        │
        ▼
Request Handler lefut

Szintaxis

Csak a port megadása

server.listen(3000);

Ez azt jelenti, hogy a szerver a 3000-es porton figyeli a beérkező HTTP kéréseket.

Port és callback

server.listen(3000, () => {
    console.log('A szerver elindult.');
});

A callback akkor fut le, amikor a szerver sikeresen elindult.

Egyszerű példa

import http from 'node:http';

const server = http.createServer((req, res) => {
    res.end('Hello Node.js!');
});

server.listen(3000);

Ezután a böngészőből elérhető:

http://localhost:3000

Mi történik a háttérben?

Amikor meghívjuk:

server.listen(3000);

a Node.js:

  1. lefoglalja a 3000-es portot;
  2. létrehozza a hálózati figyelőt (listener);
  3. várakozni kezd a TCP kapcsolatokra;
  4. HTTP kérés érkezésekor meghívja a request handler függvényt.

Portszám

server.listen(8080);

A szerver ezen lesz elérhető:

http://localhost:8080

Host megadása

Megadható az IP-cím vagy a hálózati interfész is.

server.listen(3000, '127.0.0.1');

vagy

server.listen(3000, '0.0.0.0');

Mit jelentenek?

Host Jelentés
127.0.0.1 Csak a helyi gépről érhető el.
0.0.0.0 Minden hálózati interfészen figyel, így más gépek is elérhetik (ha a tűzfal és a hálózat engedi).

Callback használata

server.listen(3000, () => {
    console.log('A szerver fut.');
});

Konzol:

A szerver fut.

Ez hasznos naplózásra vagy további inicializálási feladatokra.

Hibakezelés

Ha a port már foglalt, a szerver nem tud elindulni.

import http from 'node:http';

const server = http.createServer();

server.on('error', (err) => {
    console.log(err.message);
});

server.listen(3000);

Példa hiba:

EADDRINUSE: address already in use :::3000

Ez azt jelenti, hogy egy másik program már használja a 3000-es portot.

A listen() több paraméterrel

server.listen(
    3000,
    'localhost',

    () => {
        console.log('Elindult.');
    },
);

A listen() visszatérési értéke

A metódus a server objektumot adja vissza, így akár láncolható is.

server.listen(3000).on('error', console.error);

Kapcsolata az Event Loop-pal

A listen() elindítása után a Node.js folyamatosan figyeli a hálózati eseményeket.

server.listen()
          │
          ▼
TCP kapcsolat figyelése
          │
          ▼
HTTP kérés
          │
          ▼
Event Loop
          │
          ▼
Request Handler

A listen() tehát nem egyetlen kérést kezel, hanem folyamatosan várja az új kapcsolatokat.

Mi történik, ha kihagyjuk?

import http from 'node:http';

const server = http.createServer((req, res) => {
    res.end('Hello!');
});

A program lefut, de a szerver nem fogad kéréseket, mert a listen() nem lett meghívva.

A listen() és a close() kapcsolata

A szerver elindítása:

server.listen(3000);

A szerver leállítása:

server.close();

Összefoglalás

A server.listen() metódus feladata a Node.js HTTP szerver elindítása. Megnyitja a megadott hálózati portot, figyelni kezdi a beérkező TCP/HTTP kapcsolatokat, és amikor egy kliens kérést küld, az Event Loop közreműködésével meghívja a http.createServer() metódusnak átadott request handler függvényt. A listen() nélkül a szerver objektum ugyan létrejön, de nem lesz elérhető a hálózaton, így nem tud HTTP kéréseket fogadni. A gyakorlatban ez a metódus jelenti azt a lépést, amely a szervert ténylegesen működésbe hozza.
