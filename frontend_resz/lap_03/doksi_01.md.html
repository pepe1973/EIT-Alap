1. Módosítsuk a Nav.jsx állományt

import { Link } from 'react-router-dom';
import './Nav.css';

const Nav = () => {
    return (
        <div className="nav-kontener">
            <Link
                to="/"
                className="item1"
            >
                Főoldal
            </Link>
            <Link
                to="/buildings"
                className="item2"
            >
                Épületek
            </Link>
            <Link
                to="/register"
                className="item3"
            >
                Regisztráció
            </Link>
            <Link
                to="/login"
                className="item4"
            >
                Bejelentkezés
            </Link>
            <Link
                to="/logout"
                className="item5"
            >
                Kilépés
            </Link>
        </div>
    );
};

export default Nav;

Rövid elemzés

  • A Link elemeket a react-router-dom biztosítja, így az alkalmazáson belüli útvonalak között lehet navigálni.
  • A menü öt hivatkozást tartalmaz: főoldal, épületek, regisztráció, bejelentkezés és kilépés.
  • Minden hivatkozás külön CSS-osztályt kap (item1–item5), amelyekkel egyedileg szabályozható az elrendezésük.
  • A Nav.css fájl importálása kapcsolja a komponenshez a navigáció stílusait.

2. Szerkesszük a Nav.css állományt

.nav-kontener {
    background-color: blue;
    display: flex;
    flex-direction: row;
    gap: 2em;
    justify-content: center;
    padding: 1em;

    a {
        color: white;
        text-decoration: none;
    }
}

@media screen and (max-width: 700px) {
    display: grid;
    gap: 2px;
    grid-template-columns: repeat(3, 1fr);
    padding: 2px;

    a {
        text-align: center;
    }

    .item4 {
        grid-column: 1 / span 2;
    }
}

Rövid elemzés

  • A .nav-kontener kék hátteret, vízszintes flex-elrendezést, térközt és belső margót állít be.
  • A hivatkozások fehérek, és nincs alattuk alapértelmezett aláhúzás.
  • A 700px vagy annál keskenyebb képernyőkre szánt @media szabály rácsos elrendezést, három oszlopot és kisebb térközöket céloz.
  • A .item4 elem két oszlopot foglalna el.
  • Fontos: a képen látható CSS-ben a @media blokkon belüli szabályok előtt nincs kijelölő, például .nav-kontener. Így a display, gap, grid-template-columns és padding deklarációk önmagukban érvénytelenek CSS-szabályként. A rácsos elrendezéshez ezeket a .nav-kontener kijelölőhöz kell rendelni. A képen szereplő beágyazott a szabályok is CSS-nesting szintaxist használnak; ennek támogatása a környezettől függ.
