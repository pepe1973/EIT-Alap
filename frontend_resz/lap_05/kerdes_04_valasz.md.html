Mi az async/await és az aszinkronitás kapcsolata Node.js esetén?

Az async/await a Node.js-ben az aszinkron programozás modern szintaktikai eszköze, amely a Promise-okra épül. Nem helyettesíti az aszinkronitást, hanem egyszerűbbé és olvashatóbbá teszi annak használatát.

Egyszerűen megfogalmazva:

Az aszinkronitás lehetővé teszi, hogy a Node.js ne várakozzon egy hosszabb ideig tartó műveletre, míg az async/await egy kényelmes nyelvi eszköz ennek a működésnek a kezelésére.

Mi a kapcsolat az aszinkronitással?

Amikor egy aszinkron művelet indul:

  1. a Node.js elindítja a műveletet;
  2. a JavaScript nem blokkolódik;
  3. a művelet egy Promise objektumot ad vissza;
  4. az await megvárja a Promise teljesülését az adott async függvényen belül;
  5. közben a Node.js más aszinkron feladatokat továbbra is képes végrehajtani.

Fontos: Az await nem állítja meg a teljes Node.js programot, csak annak az async függvénynek a végrehajtását függeszti fel, amelyben szerepel.

Az async kulcsszó

Az async kulcsszó azt jelzi, hogy a függvény aszinkron.

async function hello() {
    return 'Hello';
}

Valójában ez ugyanaz, mint:

function hello() {
    return Promise.resolve('Hello');
}

Egyszerű példa

async function hello() {
    return 'Hello Node.js!';
}

hello().then(console.log);

Kimenet:

Hello Node.js!

Az await használata

function keses() {
    return new Promise((resolve) => {
        setTimeout(() => {
            resolve('Kész.');
        }, 2000);
    });
}

async function main() {
    console.log('Start');

    const eredmeny = await keses();

    console.log(eredmeny);
}

main();

Kimenet:

Start
Kész.

A main() függvény várakozik, de a Node.js közben más eseményeket továbbra is képes kezelni.

Fájl olvasása

A modern node:fs/promises modul Promise-okat használ.

import fs from 'node:fs/promises';

async function main() {
    const text = await fs.readFile('hello.txt', 'utf8');

    console.log(text);
}

main();

A readFile() Promise-t ad vissza.

Az await megvárja annak teljesülését.

Promise és async/await

Promise

import fs from 'node:fs/promises';

fs.readFile('hello.txt', 'utf8')

    .then((data) => {
        console.log(data);
    })

    .catch(console.error);

async/await

import fs from 'node:fs/promises';

async function main() {
    try {
        const data = await fs.readFile('hello.txt', 'utf8');

        console.log(data);
    } catch (err) {
        console.error(err);
    }
}

main();

Mindkét megoldás ugyanazt az aszinkron működést valósítja meg.

A Promise-ok egymás után teljesülnek.

Több Promise párhuzamosan

Ha két művelet független egymástól, nem érdemes sorban megvárni őket:

const a = await muvelet1();
const b = await muvelet2();

Ez soros végrehajtás.

Hatékonyabb:

const [a, b] = await Promise.all([muvelet1(), muvelet2()]);

Mindkét művelet egyszerre indul.

Hiba kezelése

async function main() {
    try {
        const text = await fs.readFile('nemletezik.txt', 'utf8');

        console.log(text);
    } catch (err) {
        console.log(err.message);
    }
}

main();

A try...catch ugyanúgy működik, mint a szinkron kódban.

Mire használjuk az async/await-et?

Leggyakoribb felhasználási területek:

  • fájlkezelés (node:fs/promises);
  • HTTP API hívások;
  • adatbázis-kezelés;
  • hálózati kommunikáció;
  • több aszinkron művelet összehangolása.

Callback, Promise és async/await összehasonlítása

Megoldás Példa Előny
Callback readFile(..., callback) Régebbi API-k
Promise readFile().then(...) Láncolható, jobb hibakezelés
async/await await readFile() Legolvashatóbb, könnyen karbantartható

Gyakori tévhitek

Tévhit 1

Az await leállítja a Node.js-t.

Nem igaz.

Csak az adott async függvény végrehajtását függeszti fel.

Tévhit 2

Az async gyorsabb.

Nem igaz.

Az async nem teszi gyorsabbá a programot, csak egyszerűbbé teszi az aszinkron kód megírását.

Tévhit 3

Az await csak fájlkezelésnél használható.

Nem igaz.

Bármilyen Promise-t visszaadó függvénynél használható.

Összefoglalás

Az async/await a Node.js modern eszköze az aszinkron műveletek kezelésére. A Promise-okra épül, és lehetővé teszi, hogy az aszinkron kód szinte úgy olvasható legyen, mint a szinkron kód. Az await nem blokkolja a teljes alkalmazást: csak az adott async függvény végrehajtását függeszti fel, miközben a Node.js az Event Loop segítségével továbbra is feldolgozza a többi eseményt és aszinkron feladatot.

Ez az olvashatóság, az egyszerű hibakezelés (try...catch) és a Promise-okkal való szoros együttműködés miatt az async/await napjainkban a Node.js alkalmazásokban az aszinkron programozás leginkább ajánlott megoldása.
