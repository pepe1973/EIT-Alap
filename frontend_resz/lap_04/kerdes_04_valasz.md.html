Hogyan tudunk mappákat kezelni Node.js segítségével?

A Node.js-ben a mappák (könyvtárak) kezelésére elsősorban a node:fs (File System) és a node:fs/promises modul szolgál. Ezek segítségével létrehozhatunk, olvashatunk, átnevezhetünk és törölhetünk mappákat.

A modern Node.js alkalmazásokban a node:fs/promises modul használata ajánlott, mert Promise-alapú, és jól együttműködik az async/await szintaxissal.

A node:fs/promises modul importálása

ECMAScript Modules (ESM)

import fs from 'node:fs/promises';

CommonJS

const fs = require('node:fs/promises');

1. Mappa létrehozása (mkdir())

Új könyvtár létrehozása:

import fs from 'node:fs/promises';

await fs.mkdir('dokumentumok');

console.log('A mappa létrejött.');

A projekt szerkezete:

projekt/
│
├── dokumentumok/
├── index.js
└── package.json

2. Több szintű mappaszerkezet létrehozása

Ha a köztes mappák még nem léteznek:

import fs from 'node:fs/promises';

await fs.mkdir('adatok/kepek/2026', {
    recursive: true,
});

Létrejövő szerkezet:

projekt/
│
└── adatok/
    └── kepek/
        └── 2026/

A recursive: true automatikusan létrehozza a hiányzó köztes könyvtárakat.

3. Mappa tartalmának listázása (readdir())

Tegyük fel, hogy az adatok mappa tartalma:

adatok/
│
├── kep1.jpg
├── kep2.jpg
└── lista.txt

Beolvasás:

import fs from 'node:fs/promises';

const fajlok = await fs.readdir('adatok');

console.log(fajlok);

Kimenet:

[ 'kep1.jpg', 'kep2.jpg', 'lista.txt' ]

4. Fájlok és mappák elkülönítése

import fs from 'node:fs/promises';

const elemek = await fs.readdir('adatok', {
    withFileTypes: true,
});

for (const elem of elemek) {
    if (elem.isDirectory()) {
        console.log('Mappa:', elem.name);
    } else {
        console.log('Fájl:', elem.name);
    }
}

Példa:

Mappa: kepek
Fájl: lista.txt

5. Mappa átnevezése (rename())

import fs from 'node:fs/promises';

await fs.rename('adatok', 'archiv');

A adatok mappa neve archiv lesz.

6. Mappa áthelyezése

A rename() nemcsak átnevezni tud, hanem át is helyezheti a könyvtárat.

await fs.rename('adatok', 'mentesek/adatok');

Ha a célkönyvtár létezik, a mappa oda kerül.

7. Üres mappa törlése

import fs from 'node:fs/promises';

await fs.rmdir('ures');

Megjegyzés: Az rmdir() használata új fejlesztéseknél már nem ajánlott.

8. Mappa törlése tartalmával együtt

import fs from 'node:fs/promises';

await fs.rm('adatok', {
    recursive: true,
    force: true,
});

Jelentése:

  • recursive: true → a teljes tartalom törlődik;
  • force: true → nem dob hibát, ha a mappa nem létezik.

9. Mappa létezésének ellenőrzése

import fs from 'node:fs/promises';

try {
    await fs.access('adatok');

    console.log('A mappa létezik.');
} catch {
    console.log('A mappa nem található.');
}

10. Mappa adatainak lekérdezése (stat())

import fs from 'node:fs/promises';

const info = await fs.stat('adatok');

console.log(info.isDirectory());

Kimenet:

true

További hasznos adatok:

console.log(info.size);
console.log(info.birthtime);
console.log(info.mtime);

11. Az aktuális munkakönyvtár

console.log(process.cwd());

Példa:

C:\projektek\konyvesbolt

12. Platformfüggetlen útvonalak

A node:path modul használata ajánlott.

import path from 'node:path';

const mappa = path.join(process.cwd(), 'adatok');

console.log(mappa);

13. Gyakori hibák

A mappa nem létezik

ENOENT: no such file or directory

Már létezik

EEXIST

Megoldás:

await fs.mkdir('adatok', {
    recursive: true,
});

Nincs jogosultság

EACCES: permission denied

Gyakorlati példa

import fs from 'node:fs/promises';

await fs.mkdir('teszt', {
    recursive: true,
});

await fs.writeFile('teszt/hello.txt', 'Hello Node.js!');

const lista = await fs.readdir('teszt');

console.log(lista);

await fs.rm('teszt', {
    recursive: true,
    force: true,
});

console.log('Kész.');

Kimenet:

[ 'hello.txt' ]
Kész.

A legfontosabb mappakezelő metódusok

Metódus Feladata
mkdir() Mappa létrehozása
readdir() Mappa tartalmának beolvasása
rename() Mappa átnevezése vagy áthelyezése
rm() Mappa törlése
access() Létezés ellenőrzése
stat() Mappa adatainak lekérdezése

Mikor melyiket használjuk?

  • mkdir() – új mappák létrehozására.
  • readdir() – egy könyvtár tartalmának beolvasására.
  • rename() – mappák átnevezésére vagy áthelyezésére.
  • rm() – mappák (akár teljes tartalmukkal együtt történő) törlésére.
  • stat() – fájlok és könyvtárak tulajdonságainak lekérdezésére.
  • access() – annak ellenőrzésére, hogy egy fájl vagy mappa elérhető-e.

Összefoglalás

A Node.js a node:fs/promises modulon keresztül teljes körű támogatást nyújt a mappák kezeléséhez. Létrehozhatunk új könyvtárakat (mkdir()), lekérhetjük a tartalmukat (readdir()), átnevezhetjük vagy áthelyezhetjük őket (rename()), ellenőrizhetjük a létezésüket (access()), lekérdezhetjük a tulajdonságaikat (stat()), illetve törölhetjük őket (rm()).

A modern fejlesztési gyakorlatban a Promise-alapú API és az async/await használata javasolt, mert a kód egyszerűbben olvasható, könnyebben karbantartható, és természetes módon kezelhetők a hibák try...catch blokkok segítségével.
