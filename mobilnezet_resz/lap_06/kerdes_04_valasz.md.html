Mi a feladata res objektumnak és milyen adattagjai lehetnek?

A res objektum (teljes nevén Response, típusa http.ServerResponse) a Node.js HTTP szerverében a szerver HTTP válaszát reprezentálja.

Míg a req objektum a kliens kérését tartalmazza, addig a res objektum segítségével állítjuk össze és küldjük el a választ a kliensnek.

Egyszerűen:

  • req → Mit kér a kliens?
  • res → Mit válaszol a szerver?

Mi a feladata a res objektumnak?

A res objektum feladata, hogy lehetővé tegye:

  • a HTTP státuszkód beállítását;
  • a HTTP fejlécek megadását;
  • a válasz törzsének (body) elküldését;
  • a válasz lezárását;
  • a kliensnek küldött adatok folyamatos írását.

A res objektum a createServer() metódusban

import http from 'node:http';

const server = http.createServer((req, res) => {
    res.end('Hello!');
});

server.listen(3000);

A res objektum minden kéréshez automatikusan létrejön.

A legfontosabb adattagok (property-k)

1. res.statusCode

A HTTP státuszkód.

res.statusCode = 200;

vagy

res.statusCode = 404;

Gyakori értékek:

Kód Jelentés
200 OK
201 Created
204 No Content
301 Moved Permanently
302 Found
400 Bad Request
401 Unauthorized
403 Forbidden
404 Not Found
500 Internal Server Error

2. res.statusMessage

A státuszkódhoz tartozó szöveg.

res.statusMessage = 'Minden rendben';

Ritkán használjuk.

3. res.headersSent

Megmutatja, hogy elküldésre kerültek-e már a HTTP fejlécek.

console.log(res.headersSent);

Lehetséges eredmény:

false

A res.end() után:

true

4. res.writableEnded

Megmutatja, hogy lezárult-e már a válasz.

console.log(res.writableEnded);

5. res.socket

A hálózati kapcsolat.

console.log(res.socket.remoteAddress);

A legfontosabb metódusok

A res objektumnál a metódusok használata sokkal gyakoribb, mint a property-ké.

1. res.writeHead()

Beállítja a státuszkódot és a fejléceket.

res.writeHead(200, {
    'Content-Type': 'text/plain',
});

2. res.setHeader()

Egy fejléc hozzáadása.

res.setHeader('Content-Type', 'text/plain');

Több fejléc:

res.setHeader('Content-Type', 'application/json');

res.setHeader('Cache-Control', 'no-cache');

3. res.getHeader()

Egy fejléc lekérdezése.

console.log(res.getHeader('Content-Type'));

4. res.removeHeader()

Fejléc törlése.

res.removeHeader('Content-Type');

5. res.write()

Adat küldése a válaszba.

res.write('Hello ');
res.write('Node.js');

A válasz még nem zárul le.

6. res.end()

Lezárja a választ.

res.end();

vagy

res.end('Hello!');

A res.end() után már nem lehet új adatot írni.

Egyszerű példa

import http from 'node:http';

const server = http.createServer((req, res) => {
    res.statusCode = 200;

    res.setHeader('Content-Type', 'text/plain; charset=utf-8');

    res.end('Hello Node.js!');
});

server.listen(3000);

HTML küldése

res.setHeader('Content-Type', 'text/html; charset=utf-8');

res.end('<h1>Hello!</h1>');

A böngésző HTML-ként jeleníti meg.

JSON küldése

const book = {
    id: 1,
    title: 'Node.js',
};

res.setHeader('Content-Type', 'application/json');

res.end(JSON.stringify(book));

A válasz:

{
    "id": 1,
    "title": "Node.js"
}

Több adat küldése

res.write('Első sor\n');

res.write('Második sor\n');

res.end('Vége');

A kliens ezt kapja:

Első sor
Második sor
Vége

404-es válasz

res.statusCode = 404;

res.end('Az oldal nem található.');

500-as válasz

res.statusCode = 500;

res.end('Szerverhiba.');

Átirányítás

res.statusCode = 302;

res.setHeader(
    'Location',

    '/login',
);

res.end();

Cookie küldése

res.setHeader(
    'Set-Cookie',

    'user=Peter',
);

res.end('OK');

Összefoglalás

A res objektum a Node.js HTTP szerverének válaszobjektuma. Segítségével állíthatjuk be a HTTP státuszkódot (statusCode), a válasz fejléceit (setHeader(), writeHead()), írhatunk adatot a válasz törzsébe (write()), majd a end() metódussal lezárhatjuk és elküldhetjük a választ a kliensnek. A gyakorlatban a statusCode, a setHeader(), a writeHead() és a end() a leggyakrabban használt elemek, ezekkel a legtöbb HTTP válasz egyszerűen összeállítható. Fontos megjegyezni, hogy a res objektum esetében a metódusok használata jóval gyakoribb, mint a közvetlen adattagoké, mivel a válasz összeállítása elsősorban műveleteken keresztül történik.
