Adatbázis feltöltése MongoDB

  1. Módosítsuk a Building.js állományt.
  2. Természetesen a Server.js állomány is változik.
  3. A következő JSON állománnyal töltsük fel az adatbázisunkat: FancyBuildings.buildings.json
  4. Ehhez nyissuk meg a MongoDB Compass asztali alkalmazásunkat az adott cluster-en és nyomjuk meg az ADD DATA gombot. Válasszuk az Import JSON or CSV file opciót:
  5. Keressük meg az előbb letöltött állományt.
  6. Importáljuk be a tartalmat.
  7. Íme a feltöltött collection.
