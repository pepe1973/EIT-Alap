Adatbázis létrehozás MongoDB felületen

  1. Nyissuk meg az All Project oldalt a bal felső sarokba kattintva.
  2. Majd adjunk hozzá egy új projektet a New Project gombra kattitva a jobb felső sarokban.
  3. Adjuk meg a projekt nevét Buildings, majd kattintsunk a Next gombra.
  4. A következő oldalon csak kattintsunk a Create Project gombra.
  5. A következő oldalon csak kattintsunk a Create gombra.
  6. Válasszuk az ingyenes lehetőséget. A cluster neve legyen FancyBuildings. Majd kattintás a Create Deployment gombon.
  7. Ezeket a beállításokat később végezzük el. Most kattintás a Close gombon.
  8. Lépjünk be a Database & Network Access felületre.
  9. Töröljük az adott felhasználót Delete.
  10. Majd adjunk hozzá egy újat Add New Database User.
  11. Adjunk meg nevet, jelszót és hozzáférési szintet (Built-in Role), majd kattintás az Add User gombon.
  12. Hálózati hozzáférés beállítása IP Access List.
  13. Aktuális gép címének törlése Delete.
  14. Új IP cím felvétele Add IP Address.
  15. Univerzális 0.0.0.0 cím megadása, majd Confirm.
  16. Vissza a projekt nyitólapjára.
  17. Kattintás a Clusters fülön.
  18. Kattintás a Browse Collections fülön.
  19. Kattintás a + Create database gombon.
  20. Az adatbázis neve legyen FancyBuildings. A gyűjtemény (collection) neve legyen buildings. Kattintás a Create Database gombon.
  21. Ismét vissza a projekt nyitólapjára.
  22. Kattintás a Clusters fülön.
  23. Kattintás a Connect fülön.
  24. Kattintás a MongoDB for VS Code fülön.
  25. Adatbázis csatlakozási linkjének kimásolása vágólapra. Kattintás a Done gombon.
