DELETE tesztelése Thunder Client-tal

  1. Nyissuk meg az Thunder Client API-t az Extensions fülön.
  2. Hozzunk létre egy új lekérdezést New Request.
  3. Adjuk meg a pontos URL-t és a metódust állítsuk DELETE-re. Az id értéket a GET ALL táblázatból vehetjük ki. Előtte azonban hozzunk létre egy törlendő épületet az adatbázisban.
  4. Ha jól dolgoztunk, akkor ezt kapjuk.
