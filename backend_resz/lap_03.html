Backend - Building CRUD (MongoDB)

  2. Először valósítsuk meg a CRUD műveletek közül a CREAT-et (POST HTTP metódus). Ezt és a többi műveletet is a server.js állományban fogjuk megoldani.🡆 Katt ide
  3. A teszteléshez a Thunder Client API-t fogjuk használni. 🡆 Katt ide
  4. Most valósítsuk meg a CRUD műveletek közül a READ-et (GET HTTP metódus). Ebben az esetben az összes épületet lekérjük.🡆 Katt ide
  5. A teszteléshez a Thunder Client API-t fogjuk használni. 🡆 Katt ide
