A http szerver létrehozásának lépései Node.js esetén?

Egy egyszerű HTTP szerver létrehozása Node.js-ben általában a következő lépésekből áll:

  1. A node:http modul importálása.
  2. HTTP szerver létrehozása a http.createServer() metódussal.
  3. Kéréskezelő (request handler) függvény megírása, amely minden beérkező HTTP kérést feldolgoz.
  4. A kérés (req) adatainak feldolgozása, például az URL vagy a HTTP metódus (GET, POST) kiolvasása.
  5. A válasz (res) összeállítása, például a státuszkód és a fejlécek beállítása.
  6. A válasz elküldése a kliensnek a res.end() metódussal.
  7. A szerver elindítása a server.listen() metódussal, megadva a portszámot.
  8. A szerver állapotának naplózása, például egy üzenet kiírása a konzolra, hogy a szerver elindult.
  9. A szerver tesztelése böngészőből vagy egy HTTP klienssel (például Postman vagy curl).
  10. A hibák kezelése, például a szerver error eseményének figyelésével.

A folyamat áttekintése

Az alábbi példa egy egyszerű HTTP szerver létrehozásának lépéseit mutatja be Node.js-ben, minden lépéshez tartozó kódrészlettel.

1. A node:http modul importálása

A HTTP szerver létrehozásához először importálni kell a beépített node:http modult.

import http from 'node:http';

2. HTTP szerver létrehozása

A createServer() metódus létrehoz egy HTTP szervert.

const server = http.createServer((req, res) => {
    // Ide kerül a kérés feldolgozása.
});

A callback függvény két paramétert kap:

  • req – a kliens HTTP kérése (Request)
  • res – a szerver HTTP válasza (Response)

3. A kérés feldolgozása

A req objektumból kiolvashatjuk például az URL-t és a HTTP metódust.

const server = http.createServer((req, res) => {
    console.log(req.method);
    console.log(req.url);
});

Ha a böngészőben megnyitjuk:

http://localhost:3000/books

akkor például ezt láthatjuk:

GET
/books

4. A válasz fejlécének beállítása

A writeHead() metódussal beállíthatjuk a státuszkódot és a válasz fejléceit.

res.writeHead(200, {
    'Content-Type': 'text/plain; charset=utf-8',
});

Ez azt jelenti:

  • 200 → Sikeres kérés
  • Content-Type → Egyszerű szöveg UTF-8 kódolással

5. A válasz elküldése

A res.end() lezárja a választ és elküldi a kliensnek.

res.end('Hello Node.js!');

6. A szerver elindítása

A listen() metódus elindítja a szervert.

server.listen(3000);

Ezután a szerver a 3000-es porton figyeli a kéréseket.

7. Naplózás

Hasznos kiírni, hogy a szerver elindult.

server.listen(3000, () => {
    console.log('A szerver elindult.');
    console.log('http://localhost:3000');
});

8. A teljes program

import http from 'node:http';

const server = http.createServer((req, res) => {
    console.log(`Kérés érkezett: ${req.method} ${req.url}`);

    res.writeHead(200, {
        'Content-Type': 'text/plain; charset=utf-8',
    });

    res.end('Hello Node.js!');
});

server.listen(3000, () => {
    console.log('A szerver fut.');
    console.log('http://localhost:3000');
});

Kimenet a konzolon

A szerver fut.
http://localhost:3000

Böngészőben

http://localhost:3000

Megjelenik:

Hello Node.js!

9. Egyszerű útvonalkezelés (Routing)

A req.url alapján különböző oldalakat szolgálhatunk ki.

import http from 'node:http';

const server = http.createServer((req, res) => {
    res.writeHead(200, {
        'Content-Type': 'text/plain; charset=utf-8',
    });

    if (req.url === '/') {
        res.end('Főoldal');
    } else if (req.url === '/about') {
        res.end('Rólunk oldal');
    } else if (req.url === '/contact') {
        res.end('Kapcsolat');
    } else {
        res.writeHead(404, {
            'Content-Type': 'text/plain; charset=utf-8',
        });

        res.end('404 - Az oldal nem található.');
    }
});

server.listen(3000);

Próbáld ki:

http://localhost:3000/

http://localhost:3000/about

http://localhost:3000/contact

http://localhost:3000/valami

10. JSON válasz küldése

API-k készítésénél gyakori, hogy JSON formátumban válaszolunk.

import http from 'node:http';

const server = http.createServer((req, res) => {
    const data = {
        id: 1,
        title: 'Node.js könyv',
        price: 9900,
    };

    res.writeHead(200, {
        'Content-Type': 'application/json; charset=utf-8',
    });

    res.end(JSON.stringify(data));
});

server.listen(3000);

A böngészőben vagy egy API kliensben a válasz:

{
    "id": 1,
    "title": "Node.js könyv",
    "price": 9900
}

11. A szerver hibáinak kezelése

Érdemes figyelni a szerver error eseményét is.

import http from 'node:http';

const server = http.createServer((req, res) => {
    res.end('Hello!');
});

server.on('error', (err) => {
    console.error('Szerverhiba:', err.message);
});

server.listen(3000);

Például hiba történhet, ha a 3000-es portot már egy másik alkalmazás használja.

Összefoglalás

Egy Node.js HTTP szerver létrehozásához először importáljuk a node:http modult, majd a createServer() metódussal létrehozzuk a szervert. A kéréskezelő függvényben feldolgozzuk a req objektumot, összeállítjuk a választ a res objektummal, végül a listen() metódussal elindítjuk a szervert. Minden beérkező HTTP kérés esetén ugyanaz a kéréskezelő függvény fut le, amely a kérés adatai alapján elkészíti és elküldi a megfelelő választ a kliensnek. Ez képezi minden Node.js alapú webszerver és REST API működésének alapját.
