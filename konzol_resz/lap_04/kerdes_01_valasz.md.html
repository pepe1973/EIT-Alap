Hogyan tudunk fájlokat olvasni Node.js segítségével?

A Node.js-ben fájlok olvasására a node:fs (File System) modul vagy annak Promise-alapú változata, a node:fs/promises modul használható.

A fájlolvasás történhet:

  • szinkron módon (readFileSync());
  • aszinkron módon callbackkel (readFile());
  • Promise-alapon (fs/promises.readFile());
  • streamként, ha nagy fájlokat szeretnénk hatékonyan feldolgozni (createReadStream()).

Általánosságban a modern Node.js alkalmazásokban az node:fs/promises és az async/await használata ajánlott.

1. A node:fs/promises modul importálása

ECMAScript Modules (ESM)

import fs from 'node:fs/promises';

CommonJS

const fs = require('node:fs/promises');

2. Teljes fájl beolvasása (readFile())

Tegyük fel, hogy létezik egy hello.txt fájl:

Hello Node.js!

Olvasás:

import fs from 'node:fs/promises';

const szoveg = await fs.readFile('hello.txt', 'utf8');

console.log(szoveg);

Kimenet:

Hello Node.js!

A "utf8" paraméter hatására a fájl tartalma karakterláncként (string) érkezik vissza.

3. Hibakezelés

import fs from 'node:fs/promises';

try {
    const szoveg = await fs.readFile('hello.txt', 'utf8');

    console.log(szoveg);
} catch (err) {
    console.error(err.message);
}

Ha a fájl nem létezik:

ENOENT: no such file or directory

4. Szinkron fájlolvasás (readFileSync())

import fs from 'node:fs';

const szoveg = fs.readFileSync('hello.txt', 'utf8');

console.log(szoveg);

A program megvárja, amíg a fájl teljesen beolvasódik.

5. Callback-alapú fájlolvasás

import fs from 'node:fs';

fs.readFile('hello.txt', 'utf8', (err, adat) => {
    if (err) {
        console.error(err);
        return;
    }

    console.log(adat);
});

Ez a régebbi Node.js stílus, amely ma már ritkábban használt.

6. Bináris fájl olvasása

Ha nem adunk meg karakterkódolást:

import fs from 'node:fs/promises';

const adat = await fs.readFile('kep.png');

console.log(adat);

Kimenet:

<Buffer 89 50 4e 47 ...>

A visszatérési érték egy Buffer objektum.

7. JSON fájl olvasása

adat.json

{
    "nev": "Anna",
    "kor": 28
}

Beolvasás:

import fs from 'node:fs/promises';

const json = await fs.readFile('adat.json', 'utf8');

const objektum = JSON.parse(json);

console.log(objektum.nev);
console.log(objektum.kor);

Kimenet:

Anna
28

8. Nagy fájl olvasása streammel

Ha a fájl nagyon nagy (például több száz MB vagy több GB), célszerű streamet használni.

import fs from 'node:fs';

const stream = fs.createReadStream('nagyfajl.txt', { encoding: 'utf8' });

stream.on('data', (chunk) => {
    console.log(chunk);
});

A fájl nem egyszerre töltődik be a memóriába, hanem kisebb részekben (chunk).

9. Soronkénti feldolgozás

A node:readline modullal egy szövegfájl soronként olvasható.

import fs from 'node:fs';
import readline from 'node:readline';

const rl = readline.createInterface({
    input: fs.createReadStream('hello.txt'),
    crlfDelay: Infinity,
});

for await (const sor of rl) {
    console.log(sor);
}

Ez különösen hasznos naplófájlok vagy CSV fájlok feldolgozásakor.

10. Relatív és abszolút útvonal

Relatív útvonal:

await fs.readFile('hello.txt', 'utf8');

Abszolút útvonal:

await fs.readFile('C:\\projekt\\hello.txt', 'utf8');

Platformfüggetlen megoldás a node:path modullal:

import fs from 'node:fs/promises';
import path from 'node:path';

const fajl = path.join(process.cwd(), 'hello.txt');

const szoveg = await fs.readFile(fajl, 'utf8');

console.log(szoveg);

11. Gyakori hibák

A fájl nem létezik

ENOENT: no such file or directory

Megoldás:

  • ellenőrizd az elérési utat;
  • ellenőrizd a fájl nevét;
  • ellenőrizd az aktuális munkakönyvtárat (process.cwd()).

Nincs jogosultság

EACCES: permission denied

A programnak nincs olvasási joga.

Hibás karakterkódolás

Ha UTF-8 fájlt karakterkódolás nélkül olvasol:

const adat = await fs.readFile('hello.txt');

akkor egy Buffer objektumot kapsz.

Ha szöveget szeretnél:

const adat = await fs.readFile('hello.txt', 'utf8');

A különböző olvasási módok összehasonlítása

Módszer Aszinkron Modern Ajánlott
readFileSync() ✖ ✔ Kis segédprogramokhoz
readFile() ✔ Régebbi Régi kódokban
fs/promises.readFile() ✔ ✔ Igen
createReadStream() ✔ ✔ Nagy fájlokhoz

Mikor melyiket használjuk?

  • fs/promises.readFile() – kisebb és közepes méretű fájlok olvasására, modern alkalmazásokban.
  • readFileSync() – egyszerű parancssori segédprogramokban vagy inicializáláskor, amikor nem gond, hogy a program várakozik.
  • createReadStream() – nagy fájlok, naplók vagy médiafájlok feldolgozására.
  • readline – soronkénti feldolgozáshoz (például CSV vagy log fájlok).

Összefoglalás

A Node.js több lehetőséget kínál fájlok olvasására, de a legtöbb modern alkalmazásban a node:fs/promises modul readFile() metódusa és az async/await használata a legjobb választás. Ez egyszerű, jól olvasható és könnyen kezelhető hibakezelést tesz lehetővé.

Nagy méretű fájlok esetén érdemes streamet (createReadStream()) használni, mert így a teljes fájl nem kerül egyszerre a memóriába, ami jelentősen javítja a teljesítményt és csökkenti a memóriahasználatot.
